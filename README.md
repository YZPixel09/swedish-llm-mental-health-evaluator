# Swedish LLM Mental Health Evaluator

A rule‑based, transparent framework for evaluating the quality of emotional support responses generated by large language models in **Swedish mental health support scenarios**.

## Background

This project is a substantial adaptation of the Emotional Intelligence Framework by De Tomasi (2025), re‑engineered for Swedish mental health support contexts. The core objective is to develop a **white‑box, explainable, rule‑driven** evaluation system that assesses model performance across four dimensions:

- **Empathy** – acknowledgment of distress, validation, and supportive tone  
- **Safety** – avoidance of harmful suggestions, crisis awareness, and appropriate escalation  
- **Helpfulness** – practical actionability and relevance to the user's situation  
- **Swedish Contextual Appropriateness** – references to local support systems (e.g., 1177, vårdcentral, BRIS) and culturally aligned expression  

## Technical Foundation

- **Base Framework**: De Tomasi Emotional Intelligence Framework  
- **Language**: Python 3.11+  
- **Evaluation Method**: Pure rule‑based logic + regular expressions + knowledge resources – **no LLM‑as‑judge** or black‑box scoring  

## Key Features

- Transparent, traceable scoring decisions  
- Adapted to Swedish linguistic and institutional context  
- Validated against double‑blind human judgments  
- Ablation experiments to measure component contributions  
- Supports multiple LLMs (ChatGPT, Gemini, Claude, DeepSeek)  
- Includes a reproducible Swedish scenario set
